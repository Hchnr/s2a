# 056积分参考误差分解

056完整数值与生命周期合格，但原性能门槛失败。本次仅分析已发布的96个raw/aggregate056参考，不训练、不采样、不运行机器人或fresh。

## 方法与核验

新增 `src/s2a/reference_error_decomposition.py`，对每个右乘local增量精确分解：

`R_pred d_pred − Δp_truth = (R_truth d_pred − Δp_truth) + (R_pred − R_truth) d_pred`。

前项为按真实局部坐标系计算的平移增量误差，后项为预测朝向与真实朝向差造成的坐标系耦合。各项沿时间累积，向量之和严格恢复实际积分位置误差；平方误差必须加有符号交叉项，不能把两项当成独立百分比归因。这里的真实朝向仅作离线诊断，不能进入在线输入。

`scripts/analyze_wam_reference_decomposition.py`实际检查六个053 archive、全部96个请求及H8/H16/H40，当前state/sim SHA/时钟/mask绑定通过；逐请求位置/开度误差和12个全体指标与原评分在绝对容差1e-12内复现。消费输入前后SHA不变。产物 `outputs/clean_on_policy_aggregation_20261024/aggregate_validation/reference_error_decomposition.json`。三项实际几何测试覆盖纯朝向耦合、连续平移偏差和非单位初始TCP朝向，全部通过，Ruff及格式检查通过。

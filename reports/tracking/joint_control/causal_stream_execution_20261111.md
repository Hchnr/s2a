# 连续执行与独立重放的 CPU 模拟

2026-11-11。延续[流协议阶段](causal_stream_protocol_20261111.md)，新增连续执行
适配器：每次只接入一个已接受的当前参考，复用原八周期执行函数，实际完成一个
周期并提交反馈后才允许下一动作；满八周期后保留上一条命令和策略历史，才允许
重新观测。模拟测试覆盖三窗口 24 个周期及 600 个假内环步。源码将开发阶段上限
固定为六窗口；真实外层运行时尚未登记或开放这一长预算。

图像到参考适配器复用原 renderer 合同，检查前后状态、时间、相机角色、PNG SHA，
将当前 PNG 和公开任务交给协议，再以当前 TCP anchor 解码已接受的 H40。请求和
响应分别独占写入 runtime 目录；发送尝试、发送完成、响应接收、响应接受和策略
准备分开计数。错误响应和参考门拒绝时不派发动作。实际两窗口历史参考逐元素
一致的门尚未接入正式运行，当前门与模型服务均为测试替身。

中途异常时，保留已派发命令和已观测的部分内环采样，并分别记录 attempted、
completed 和反馈提交数；内环缓冲丢失、无质量 witness 或状态在等待/渲染/反馈
提交期间变化会阻止下一次派发。测试还在隔离子进程中执行原 prefix runtime 的
实际 audit-hook 函数体，确认继承 socket 与登记图像读取可用、运行目录外写入
仍被拒绝；这不是整个 OSMesa runtime 的运行证明。

独立重放器不导入候选反馈策略或模型 adapter，只对完整记录的命令运行旧八周期
执行器，核对 endpoint、25 个内环样本、TCP 误差和任务标签。重放中的目标由调用方
独立提供，调用方仍须验明生产记录和响应来源；未完成的 in-flight 命令在重放前
被拒绝，生产者报告的停机原因也不会被重放器自行认证。假环境中独立重放三窗口
24 个命令，篡改内环或参考的对照按预期失败。

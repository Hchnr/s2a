# 因果流协议与自有进程 CPU 验证

2026-11-11。按[连续执行设计](../../../docs/architecture/causal_wam_streaming.md)，
实现本地 socket 帧、仿真侧状态账本、模型侧独立请求准入，以及两个自有子进程的
启动、失败传播和实际回收。本阶段只运行 CPU 模拟服务，模拟的 16 个周期与两次
响应均不是物理执行或真实模型调用。

本地帧使用有界长度、完整读取和单次总超时；重复 JSON 键、非有限数、异常帧、
断连或超时会令通道失效。账本绑定请求号、当前图像 SHA、实测状态 SHA 和仿真
时间，要求每个窗口收到合法响应并登记八个连续周期，每周期登记 25 个内环样本。
模型侧独立核对固定任务、seed、模型身份、去噪预算和请求顺序；传给模拟模型的
只有当前图像字节与公开任务。图像只允许从仓库 outputs 的登记目录读取，并在
服务消费时重新校验 SHA，不跟随路径符号链接。

双子进程测试使用真实 socketpair 和独立 Python 进程，完成两个模拟窗口；另测试
子进程异常、部分启动失败及超时，核对所有已启动子进程实际 wait/reap。登记的
状态与内环样本目前由调用方提供，协议本身不证明它们来自实际物理，也不替代
控制安全门、权重来源核验、独立 checker 或 GPU 准入。

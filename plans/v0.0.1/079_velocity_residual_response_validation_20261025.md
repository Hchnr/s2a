# 079 新响应数据的隔离验证与速度状态残差前向模型

在查看078干预后的响应误差前，固定下一阶段数据划分和唯一模型。078数据采集/机械检查只验证实际记录，不包含本候选性能结果。此登记不自动开始fit，必须先完成全部12条独立采集与生命周期检查。

## 数据和隔离

原30native轨迹保持24fit/6内部留出。新12条中，三条baseline不新增训练行，所有分支anchor前共享前缀均不新增训练行。只取anchor起24个响应周期；每任务open/close分支用于fit（case01/03、05/07、09/11，共144周期），retain分支case02/06/10只作新的命令响应验证（72周期），不得用于标准化/参数/模型选择。共享初态及历史是设计事实，因此它验证已知训练初态上的未拟合命令分支，不宣称独立新初态或最终泛化。原6条内部留出已用于多次诊断，证据属性不变。

最终fit权重：原24fit总体0.5、逐轨迹等权；新6个fit干预总体0.5、逐分支等权，各轨迹/分支内周期等权。无prefix重复加权。不拟合078三baseline或retain响应，也不拟合074闭环失败数据。所有输入、行范围、来源SHA与参数冻结。

## 唯一固定模型

q为当前归一化实测opening；V=0.05*(当前finger1速度-finger2速度)/0.079，为当前瞬时速度在一个控制周期的开度量。速度来自已核验当前观测，不能用未来q差代替。m为当前真实motor cache首分量，m_next由当前m和已知candidate native命令按25个子步推得。四连续输入[q,m,m_next,V]，fit统计标准化、全部二阶交叉与bias共15维。

固定常速度物理先验q_next=q+V、V_next=V。学习两列残差[(实际q_next-q)-V, 实际V_next-V]，同一FP64 ridge0.001、bias不罚，每列同一设计矩阵独立求解。仅fit一份，不扫描lambda/特征/窗口，不按任务或接触切换。预测q_next=clip(q+V+residual_q,0,1)，预测V_next=V+residual_V；不以未来实测或native未来motor替换模型递推。

此先验的动机是当前速度直接描述慢开响应；不是已证明根因或预设胜者。075因固定响应在慢开段高估运动失败，当前速度审计不足以证明“加速度就会修复”，故必须独立性能验证。

## 固定评价与准入

先全部数据/行/速度/命令状态重建及独立增广最小二乘核验。冻结候选参数后才评价原6内部留出和新3retain分支，每条分别报告一步q误差、最长8周期已知命令下无未来q/V注入的局部rollout q误差，以及V预测误差、非有限/越界情况。

主要门槛沿用state而非motor重建：所有9条的一步q和8步q RMSE均不劣保持当前q基线；V误差单列，不把它代替q或任务成功。常速度先验和冻结075同样作为对照，不要求预设胜者。任何非有限rollout直接失败，不通过临时clip V掩盖。新分支只评估其24周期响应，8步尾部不足则mask，只评价实际存在端点。

原075及本候选都必须保留失败，不因“旧模型已失败”而降低门槛。离线通过后仍需另行登记统一逆控制与正确参考物理回归，再原WAM开发5/6各任务1/2、fresh20/24各任务4/8。此阶段0新物理/模型/fresh，总目标不缩减。

# 203 预测跟踪限速核心与保存状态数值核验

202核心tracking_guarded_rate对各轴夹紧断点枚举分段，使用稳定二次根计算最小可行change，无解返回原命令。5项需求测试包括切点、常值映射、无解、边界及60组随机耦合系统与独立polynomial roots对照。

check_tracking_guard_saved_states仅在200已机械审查case00的记录仿射映射上检验数学核心：37个加载/支持内状态，其中24可行、13无解回退。原164步其余route/支持外不额外限速。所有结果是同记录状态反事实，不是完整闭环，也不是独立物理映射正确性证明。

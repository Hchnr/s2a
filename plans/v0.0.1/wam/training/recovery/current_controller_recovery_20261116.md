## 固定对照

沿用 063 三个训练 demo、seed42、基座 x 偏移 `0、+0.02、−0.02 m` 和顺序，
共九条；每条从原 reset 开始，一次初始化后先以 16 个 20 Hz 端点移动到偏移目标，
再用 40 个端点返回初始目标，夹爪维持初始参考；之后跟踪对应原 native 实测
source 轨迹及原开度。其 source→TCP、坐标系、0.05 s 控制 / 0.002 s 内步与
原合同一致。该参考是训练正控的特权教师，不能用作在线 WAM 输入。原目标只是
控制参考，训练标签只能由本次每步**实际测量**的连续状态形成。

固定使用[无界 seed 优先](../../../../../reports/tracking/joint_control/cached_seed_preference_cohort_20261116.md)
的当前分段策略、当前夹爪和原独立 witness，不按案例选策略，不引入历史专家
动作或物体真值作在线输入。与 063 的控制/夹爪实现不同，因此若结果变化不能
单独归因给某个组件。沿用原三个训练源和 forbidden 初态表，验证不与已登记的
validation/development/fresh 初态重叠；不得访问旧工作区或将开发/留出用于拟合。

记录 reset、每个已完成端点的真实 source/site/body/TCP、opening、时间、完整
sim state 与 motor cache；在实际端点 0、16、56 各渲染当前图像，不推进物理。
以实际连续端点构造 local SE(3) delta、Action128 与有效 mask；若中途停止，
只保留真实前缀，末端动作无效，缺失图像和未来窗口不得补造。只有存在至少 40
个后续真实周期的 anchor 才可成为完整 H40 训练窗口，本次不拟合或扩充训练集。
此处 Action128 的开度槽记录**下一端点实测开度**；实际七维控制命令另存，不能
把二者当作同一标签。未来拟合前还须核对目标模型的数据域和开度槽语义。

## 评价、资源和边界

原计划每例分别为 220、310、239 周期；每阶段总计最多 **2,307 控制周期 /
57,675 个 2 ms 内步**，9 个 CPU/OSMesa worker、27 个模型及 context。保持原
命令、变化率、pose、`0.05 rad` 关节缓冲和 per-step 搜索预算；不得自动重试。
分别报告实际偏移与返回误差、各自 pose/RMSE/关节指标、末 40 原生任务谓词、
停止原因及有效 anchor，不将部分前缀计为完整成功。

独立 checker 从相同 reset 重放本次已执行动作，逐端点核对状态、动作、内步、
夹爪与任务标签，重新采集已到达的三张当前图像；不运行候选，不独立重算停止
决策。独立重建 TCP、local delta、Action128、mask 和时间，并核对图像/状态绑定。
九例各自完整重放、所有当前图像和标签核验正常后，单独报告三条零偏移正控及
六条非零扰动；零偏移须全部完整、末 40 成功并达原 RMSE / 关节缓冲门。非零
case 的完整稳定、对应 anchor 和标签单独标记，不将失败数据说成合格教师。

运行前做 64 并发相关 CPU 回归与零物理预检，记录源码、训练来源和独占进程
收据。0 新 WAM / GPU / fresh；即使九条均成功，也不证明模型学会恢复、真实
WAM 闭环或原 24 条最终验收。只有证据完整后才另行决定训练集资格和后续拟合。

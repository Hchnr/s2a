# 恢复候选种子编码补充说明

2026-11-16。[候选数据准备计划](recovery_candidate_data_20261116.md)中
“SHA-256 前 63 位”的表述不够精确。本次实现和已保存的候选种子实际采用：
对固定规范 JSON 的 SHA-256 摘要取**前 8 字节**，按无符号大端解释，再与
`(1 << 63) - 1` 按位与，即保留该 64 位整数的低 63 位。

原计划和已生成产物不改写。独立检查器按该实际字节算法重新计算所有 216 个
候选种子，并检查同批、原 D0 及 42/43 的碰撞；这些种子未被任何模型请求
消费，未授权训练。未来的模型实验仍须单独固定种子配对和完整执行合同。

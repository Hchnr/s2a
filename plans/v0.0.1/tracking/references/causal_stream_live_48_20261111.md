# 最多六窗口的真实 WAM 连续开发试验

2026-11-11。延续[两窗口真实模型结果](../../../../reports/tracking/references/causal_stream_live_wam_20261111.md)，
在同一 correct_08 初态、seed 42 和正确参考前 80 周期历史下，最多连续执行六个
八周期窗口，以观察末尾是否出现 40 个连续任务成功端点。前两窗口的当前图像、
状态、时间和实际 WAM 输出仍需与独立审核过的 step80、88 逐项一致；之后仅使用
当时实际采集的图像、公开任务和固定 WAM 采样生成新参考，不读取未来正确轨迹或
任务成功标签作为模型/控制输入。

固定 GPU UUID `GPU-c0b598ba-0a6e-73af-bbcc-97bc89379bdf`；最多一次模型初始化、
六次请求、每次 35 步、总计 210 次去噪。producer 与独立 checker 各最多 128 个
控制周期、3,200 个 MuJoCo 内步，包含 80 周期已登记正确参考前缀；新初态、训练、
自动重试均为 0。每次实际发送、模型执行、去噪、mask、响应、已派发命令及内环
尝试/完成均分别记录，失败或中断保留全部可观测消耗，不静默扩大预算。

前三、四、五、六次请求仅能分别在完成前一段八周期反馈后发出。任何生成失败、
无质量 witness、关节缓冲丢失、状态/时间或通信身份不匹配均在下一次动作派发前
停止；通过显式停止消息结束等待中的模型服务，不把受控早停记为完成全部预算。
任务成功谓词只供离线评价，不用于选动作、重规划或提前结束。独立 checker 仅重放
实际完整命令和内环；不能重放的 in-flight 样本、策略停机原因及中断用量明确保留。

源码、163 个 checkpoint 文件、当前 GPU UUID 与可见进程需在启动前核验，CPU 端
显式空 CUDA/LD，模型按 UUID 隔离；所有缓存、临时文件和输出在本仓库，外部参考
与权重只读。推理等待时仿真暂停，记录墙钟延迟，不据此声明实时能力。完整六窗口
也仍是一个已研究初态上的开发结果，不等同 600 周期、18/12/24 留出资格或真机。

启动前必须完成长预算历史兼容检查、真实请求循环和安全早停的 CPU 假服务测试、
64 路相关回归、零模型/零物理 dry 与只读源码/权重 SHA preflight。任何步骤不通过
均不启动模型或物理进程；若后续运行失败，需先记录实际用量并重新登记预算。

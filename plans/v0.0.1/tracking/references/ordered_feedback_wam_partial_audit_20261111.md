# 双次 WAM 响应的失败旁证与离线诊断

2026-11-11。原两图诊断的唯一 GPU 工作者完成一次模型初始化、两次请求和 70 次
denoise 后，在汇总阶段因要求 `len(mask_evidence) == 1` 失败；该列表由每次
推理准备追加，不应将单请求检查直接用于双请求。失败收据记录 70 次 attempted
和 completed、两份完成响应及各自 SHA；进程 exit1，owner 实际 wait/reap，设备
无残留显存或计算进程。原 GPU 预算已经耗尽，不重新初始化或请求。

独立 CPU 审查固定失败收据、原模型源码提交、前置源码/权重核验、owner 退出、
两个请求与响应、当前图像及任务文字，检查响应形状、mask 和有限性。随后仅对
已保存的两个预测，在各自实际 TCP anchor 下解码并与先前固定的正确参考做 H8/H40
位姿和开度离线比较。不重启模型、不产生物理步、不更改已执行结果或修补缺失的
内存 ledger；保存的失败状态和无法独立恢复的 initial-noise 证据仍明确保留。
该旁证只支持所保存响应的有限数值诊断，不把原 GPU 运行改记为成功、不代表 WAM
闭环或任务验收。

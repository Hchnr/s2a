# 精确状态端点缓存的真实 WAM 连续开发试验

2026-11-11。先前六窗口试验因重复端点读取改变物体四元数浮点字节而在 step120
终止；后续 CPU 回放和旁证见[报告](../../../../reports/tracking/references/causal_stream_endpoint_cache_replay_20261111.md)。
本计划登记一次**新的**真实模型与物理预算，不覆盖失败产物、不自动重试。

固定 correct_08、seed 42、正确参考前缀 80 周期与固定 WAM checkpoint；最多六个
八周期窗口。每个动作的实际端点按原生状态 SHA 和时间缓存，同步状态完全一致时
复用，状态或时间变化则停止；不直接修改仿真状态。模型只接收当前图像和公开任务，
每段完成后才生成下一参考。前两个请求及前 16 个反馈周期保留原先审计过的匹配门；
后续不读取未来正确参考或任务标签。任务谓词仅离线评价，不用于动作选择或早停。

本次最多一次模型初始化、六次请求、每次 35 次去噪、合计 210 次去噪；producer 与
独立 checker 各最多 128 控制周期、3,200 MuJoCo 内步，包含前缀；新增初态、训练、
重试均为 0。若出现不一致、安全停止或中断，保留实际已用预算和全部收据，不能
把有界早停当成完整六窗口。GPU 显式限定已授权 UUID；推理期间仿真暂停，分别记录
模型和物理证据，不能据此声称实时。

启动前必须完成新缓存包装在 producer/checker 的 CPU 假服务测试、64 路相关回归、
零物理/零模型 dry、原模型源码和 checkpoint 的只读 SHA preflight 及 GPU 空闲检查。
独立 checker 只读取实际完成的模型参考和动作，使用自己的现场端点，按既有数值
容差比较跨运行记录，同时严格验证每次当前图像与本次运行的状态绑定。即使 48 周期
完成，这仍是已研究初态上的开发试验，不能替代 600 周期、18/12/24 留出资格或真机。

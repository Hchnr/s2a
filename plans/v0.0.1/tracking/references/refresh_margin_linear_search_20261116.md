# 刷新余量的单次局部线性化搜索

2026-11-16。针对[同一状态上的 SLSQP 预算耗尽](../../../../reports/tracking/references/refresh_margin_targeted_search_20261116.md)，
只在同一个已完成 baseline 计划及其当前因果输入上构造一次线性化搜索，检验是否
能用更低的局部模型成本找到合格替代。它不是控制部署，也不以此初态代替留出评估。

保留原 box / 变化率、线性关节 / 制动 / 终端约束；将原第一点余量、第二点位置
`0.00925 m` / 旋转 `0.0455 rad` 与后六点 `baseline future slack + 0.02` 条件
在基线计划处线性化。将每个编码动作分量的改变量限制为 `±0.1`，一次 HiGHS
线性规划最小化动作改变量的 L1 范数。目标与约束、信赖域和单次预算在运行前固定，
不以本状态结果扫描阈值。线性化不可行仅说明此局部约束问题未找到解；它不能
证明真实可行域为空。

基线响应须复现原独立 witness；若线性规划返回候选，最多额外求值一次真实冻结
局部模型，再逐项核对原约束和实际非线性 pose / slack 条件。只有合格候选才做
独立八周期 witness 审核；线性化数值本身不授予资格。无合格候选时不进行物理
对照。即使模型审核通过，仍须另行登记同状态实际执行、独立重放和跨案例验证。

额外预算为 1 个静态 MuJoCo 模型、1 个预览模型、1 次静态 forward、2 次局部
模型响应、1 次线性规划及至多 1 次独立八周期 witness 审核（200 次端点查询、
2,600 次模型内步）。不覆盖或重试上次 320 响应结果；0 物理步、0 WAM、0 GPU、
0 fresh，不自动重试，所有 worker 实际 wait/reap。原基线成本与额外成本分别记录。

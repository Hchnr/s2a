# 双 seed worker：旧开发图像的单次真实 seed 43 推理

2026-11-13 预登记。[双 seed 接口](adaptive_multiseed_interface_20261113.md)
已通过 CPU 合成联测，但真实模型尚未使用新 worker。为验证真实采样身份，
选择 task0/init0 既有开发轨迹的第 0 张图像；该图像及 seed 42 响应先前已
在同一 checkpoint 下复现。本阶段不派发任何机器人 action，也不使用最终留出集。

## 固定输入与预算

- [配置](../../../configs/tracking/references/adaptive_multiseed_real43_20261113.json)
  固定旧开发案例记录、首图 SHA、记录的物理端点、旧 seed 42 响应及其复现、
  模型权重清单指纹、源码和 163 个权重文件。物理端点只用于重放帧来源绑定，
  不是本次运行的现场状态；世界模型仍只接收保存的图像和公开任务。
- 在唯一指定 UUID 上初始化一次既有 `8400_masked`，以 seed 43 发出一次 H40
  请求、最多 35 次去噪；零模型训练、零仿真模型、零物理步和零 fresh。
  不自动重试，失败及已发生或无法确定的开销均保留。
- 测试通过、源快照一致、权重与源码哈希核验、独立 CPU OpenCV 探针和 GPU
  空闲确认后才执行。独立 CPU 重放客户端与模型 worker 用受限 Unix 帧连接，
  各进程实际 wait/reap，记录失败收据和 GPU 释放。

## 评估与边界

核对请求、实际响应和 envelope 均为 seed 43、原任务、模型和 mask，实际
35 次去噪完整，输出为有限的 40×128 数组且后 118 维为零。对同图像的旧
seed 42 响应报告逐数组最大差、RMSE 和不同元素数；不预设差异大小或据此
判断任务成功。检查旧 seed 42 原始响应与既有复现一致并保留来源。

该单次结果仅验证保存图像上的实际模型及接口，不构成现场闭环、不同初态
泛化、600 周期稳定、多任务验收或真机证据；不根据结果修改原验收门槛。

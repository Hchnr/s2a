# 三任务开发轨迹中的参考切换

2026-11-13。已有六条旧开发轨迹全部提前停止，213 个当前图像 WAM 请求及动作
已记录并独立重放；其中四条的闭合意图和部分重规划次数已事后查看。本次同样
是回顾分析，不使用最终留出，不将其描述为盲态评测或因果反事实。

使用全部六条各自记录的 H40 响应、生成时的实测 TCP 锚点和固定工具变换，
核对响应与模型输出逐值一致。对每一对连续请求，若前一参考已消费 n 个端点，
则旧预测端点 n 与新预测端点 0 均对应下一个 20 Hz 物理端点；在共同世界坐标
计算位置距离、SO(3) 角距离与开度差。分别记录质量触发及固定窗口结束，按
案例保留完整分母；记录 H40 中已生成、已消费及未消费的 opening≤0.2 端点，
以及旧端点≤0.2 而新端点≥0.8 的切换计数。这两个开度水平仅是固定描述条件，
不是抓取或安全成功定义。

实际下一个动作是根据新参考选择的；比较旧/新参考不证明若坚持旧参考就能
成功，也不证明两种预测之一正确。不得根据对象状态或成功谓词修改参考。
只读取已保存的模型响应和现有物理记录，不新增模型、仿真、拟合或最终留出；
三任务只有三个旧初态，两个 seed 与周期均相关。原 18 条正确参考、12 条 WAM
开发及 24 条最终验收条件保持不变。

首次只读扫描遇到最后一个停止段没有 `boundary` 字段而报 `KeyError`，没有输出
结果或新增模型/物理工作；修正为允许终止段缺少该字段，非终止切换仍要求明确
边界，保留该失败记录并重新执行专项回归。

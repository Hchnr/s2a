# 刷新余量候选的未来质量约束

2026-11-15。在[候选设计](refresh_margin_preference_20261115.md)基础上，实际
候选选择增加以下预先固定条件：探索候选的原 `future slack` 相对默认选中值增加
不得超过 `0.02`（原归一化量）。该条件避免仅为延迟刷新而任意牺牲余下轨迹的
模型质量；若没有满足条件的候选，按原设计逐值回退默认选择。它不放宽原 pose、
关节、命令、witness 或 response 预算，也不声称实测安全。

该补充在任何候选求解或新物理执行之前固定；原计划字节保持不变，以免破坏已
完成的刷新事件回顾分析中保存的输入指纹。

# 基于当前夹爪几何的桌面参考投影

2026-11-11。[容差证书](../../../../reports/tracking/response_models/reference_table_tolerance_20261111.md)
表明，固定当前夹爪配置时，correct_08 的部分已生成目标无法同时满足原位姿容差
与桌面无相交。本阶段设计一个**可选**因果参考投影候选：只消费当前可测夹爪
配置对应的 TCP 局部碰撞顶点、已生成目标和事先提供的桌面盒体标定；不读取
仿真接触力、对象状态、未来实测状态或任务成功标签。默认控制路径不改变。

在桌面坐标系下，将目标 TCP 的当前夹爪顶点包络与桌面 XY 矩形比较。按显式位置、
SO(3) 和夹爪形变上界扩展顶点包络；若扩展 XY 包围盒与桌面不交，保持原目标。
否则求沿桌面法向向上的最小平移，使每个顶点在上述误差范围内的最低可能高度
不低于桌面顶面加明确净空。保留目标旋转和夹爪参考。平移超过配置上限时返回
显式拒绝，不派发或偷偷放宽上限；记录投影前后目标和对原参考的位置偏差。

误差包络是**条件假设**：只有当前碰撞顶点、标定盒体、夹爪形变界和实际 TCP
位姿误差界均成立时，才对该 finger mesh 与桌面盒有效。它不覆盖其他机器人部件、
炉具、对象、连续路径或未知环境，也不保证控制器能跟踪投影目标。特别地，以下
固定形变界 0 仅用于静态研究，不能假定执行中夹爪不动。桌面盒由本次仿真模型
提供用于离线评估；部署时必须另外取得经验证的标定，不能把对象或场景真值当作
默认在线输入。

先按[配置](../../../../configs/tracking/response_models/tabletop_reference_projection_20261111.json)
在 47 个已审核开发状态上只读比较原目标、零位姿误差投影及原 0.01 m / 0.05 rad
包络投影，固定净空 0.001 m 和最大修正 0.05 m；两候选均固定形变界 0，逐行报告
拒绝、参考偏移、静态碰撞和原目标误差。每次只用该决策时的状态和已生成目标；
状态沿原轨迹，不构成改变策略后的闭环。最多 1 个 native 模型和 188 次 `mj_forward`，
零物理积分、WAM/GPU 调用及新初态。先做零工作 dry、32 并发几何/因果测试和
来源核验，worker 实际 wait/reap；失败不覆盖或自动重试。

若静态结果支持候选，必须另行登记共享控制接口、原始和投影参考双评分、有限
控制与内环预算、夹爪形变条件及独立 checker，然后在自身实际历史下进行物理
反馈。不能将投影参考达标当成原参考达标，亦不能以单初态局部结果替代原 18/12/24
及每条 600 周期的最终标准。

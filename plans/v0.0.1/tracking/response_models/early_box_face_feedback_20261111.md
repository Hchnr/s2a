# 提前两周期的同参考多方向物理对照

2026-11-11。[step120 才介入的物理对照](../../../../reports/tracking/response_models/box_face_feedback_20261111.md)
中，多方向候选五周期无桌面/炉具有效接触，但 0/5 端点达到自身目标，且 125 个
积分前样本均未满足其 1 cm 位置误差界；首周期向下的上一条命令又受 0.25 动作
变化率限制。提前介入可能改善当前目标跟踪，但不能预设成功或改变原参考门槛。

## 同起点与参考

从 correct_08、seed 42 原初态完整重放至 step118，核对原生状态 SHA、TCP、
夹爪顶点、上一命令及控制器/夹爪缓存；两组共同分叉。两个 producer 分别用原
目标或多方向投影，从 step118 最多执行到 step125，每周期均使用**step112 当前
图像当时已生成的同一 H40**中对应的原目标（游标 6–13）及本分支当前测量。
因此两组参考和初始条件相同；不在 step120 请求或使用新图像的模型响应。参考
随时间变旧，不把结果解释为每周期重新观测的 WAM 性能。模型、控制器、夹爪命令、
原动作盒、`0.25` 变化率和每周期测量接口一致；任务标签、未来实测和接触数据
不参与策略决策。

两组对机械臂 `0.05 rad` 缓冲、当前夹爪关节额定范围均采用同样的派发前停止门；
发生实际内步机械臂越限后停止。投影组额外遵循 `0.05 m` 原参考平移上限及条件
几何包络；不满足则在动作派发前停止。两个独立 checker 不加载候选策略，只重放
各自已派发动作，核对 25 个内步、接触、力矩、TCP/夹爪测量和参考；不独立重算
策略或停止原因。比较两组实际完成的共同前缀，分别报告停止点、原目标/所选目标
误差、接触、关节与力矩、任务/抓取标签，以及投影条件是否在实际采样中成立。
状态不同后应持续使用各自反馈，不能把旧轨迹的下一状态提供给新策略。

## 预算与证据

先完成 CPU 专项、零原生模型/零物理 dry，登记后一次 producer 组与一次 checker
组；每组两进程使用独立 outputs 目录。每进程上限 `126 × 25 = 3,150` 个物理
内步，运行时计数器强制限制；总计最多 **12,600 内步、16 条新命令、12 次 native
模型和 12 个 OSMesa context**。0 次新 WAM 请求/去噪/训练、0 个新初态；所有
worker 必须实际 wait/reap。失败和提前停止保留，不覆盖、不自动重试。前次相关
链已消耗 37,050 内步，且更早参考生成另有成本，本次上限是独立新增预算。

# 固定夹爪配置下的位姿容差与桌面冲突

2026-11-11。[静态参考核查](../../../../reports/tracking/response_models/reference_table_geometry_20261111.md)
发现 correct_08 的 step120–126 目标代理与桌面相交，但接触距离本身不能证明
原 0.01 m / 0.05 rad 误差容差内不存在无碰撞配置。本次固定
[配置](../../../../configs/tracking/response_models/reference_table_tolerance_20261111.json)，
对这七个已有决策状态和当时已生成目标建立**保守几何证书**，用于决定是否需要
调整参考层；不派发动作，不使用留出初态。

仅针对已登记 `gripper0_finger2_collision` 的当前夹爪关节配置和固定盒形桌面，
将同一编译 MuJoCo 碰撞 mesh 的每个顶点变换至目标代理的世界坐标及桌面局部坐标。
对每个顶点，计算它到盒体六个面的最小内部余量 `m` 和相对目标 TCP 的距离 `r`。
任一 TCP 位置变化范数不超过 `p=0.01 m`、SO(3) 旋转测地角不超过 `theta=0.05 rad`
时，这个固定夹爪材料点最多移动 `p + 2 r sin(theta/2)`。若某顶点严格位于盒内，
且 `m` 大于该上界加 `1e-9 m` 数值余量，则无论允许容差内如何改变 TCP 位姿，
该点仍在桌体内部，因而该固定夹爪配置必然与桌面几何相交。逐顶点枚举、选择
最大证书余量；没有证书只记为**未判定**，不能称已找到无碰撞配置。

检查模型几何类型、collision mask、mesh 顶点与目标 TCP/桌面坐标、现有静态碰撞
查询、当前关节配置及输入/源码 SHA。证书针对桌面盒与一个固定夹爪配置，不排除
改变夹爪开度、场景几何或容差后可行；它不证明 IK、连续路径、物理接触力、
机器人运动或任务成功，也不将仿真场景真值作为在线输入。必须用已保存目标和
当时已完成状态，不借用未来状态或任务标签。

最多一个 native 模型、14 次 `mj_forward`（七个状态各恢复和目标对齐一次）、
零物理积分、零 WAM/GPU 调用和零新初态。显式禁止 `mj_step*`，限定每次 forward，
先运行零模型 dry 和 32 并发数值、几何及来源测试；worker 真实 wait/reap，失败
保留且不自动重试。已记录的 18 正确参考、12 开发与 24 最终留出门槛不变。

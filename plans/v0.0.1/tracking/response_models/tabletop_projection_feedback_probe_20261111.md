# 桌面投影的短窗口物理反馈对照设计

2026-11-11。静态对照及其独立复核见
[报告](../../../../reports/tracking/response_models/tabletop_reference_projection_20261111.md)。
本设计先限定一个能够保持参考因果身份的物理实验；它不是完整任务验收，也不把
静态净空视为控制或路径安全保证。

## 相同初态和已生成参考

使用已独立重放的 correct_08、seed 42 开发轨迹。各分支重放相同的正确参考
step0–79 和历史已执行命令 step80–119，逐周期核对命令、状态和全部 25 个内步；
step120 的状态 SHA256 必须为
`977c527f571f3b03b56f66118612027a8d4835c5fc9f9b9afea637f4a029e33c`，
并与原 step120 图像/响应记录绑定。检查各分支控制器目标、上一命令及夹爪
内部状态一致；不一致则不派发新命令。

只使用该**分叉前** step120 图像已经生成的目标，执行 step120–126 最多七个
50 ms 周期，在 step127 前停下。不得把之后由原轨迹图像生成的历史参考冒充
投影轨迹的新观察响应；也不调用 WAM，不读取未来实测状态。沿分支自身的实时
状态逐次计算动作，不能把原轨迹状态回放当作投影后的物理反馈。

## 对照和输入

三分支分别为原目标、零位姿误差投影、`0.01 m / 0.05 rad` 位姿包络投影；均
使用相同因果单步 OSC 位置/旋转比例反馈、相同固定机器人及控制器，位置和旋转
误差增益固定为 1，经原 `OSCInterface` 编码限幅，机械臂动作相对上一实际命令
每周期最多变化 `0.25`。夹爪在七周期内使用分叉时的上一实际夹爪命令，三个
分支规则一致；这只是隔离桌面投影影响的短窗口试验，不能代表完整夹爪策略。
该简单反馈不是先前质量优化策略，结果不得直接归因于单独改变参考与先前优化
策略间的差别。

投影每个决策从当前实测 TCP 和夹爪关节运动学重建 finger2 mesh 顶点；桌面
作为事先给出的固定盒体标定，世界坐标中心 `(0, 0, 0.875) m`、旋转单位阵、
半尺寸 `(0.5, 0.6, 0.025) m`。这组数值来自该仿真场景的已审计离线模型，
不是已完成的真实世界标定。净空 `0.001 m`、数值余量 `1e-9 m`、最大目标
平移 `0.05 m`、夹爪形变界 `0 m`；超上限、不完整几何或状态不合法时在派发前
拒绝并记录原因。目标旋转和生成的夹爪参考不得被隐式改写。

原始世界模型目标和投影目标分别保存；逐物理端点报告相对二者的 TCP 平移与
SO(3) 误差、原有 `0.01 m / 0.05 rad` 位姿门槛、实际任务标签及夹爪关节状态。
逐 2 ms 内步在环境既有 `sim.forward` 和控制器计算之后、积分之前读取 TCP、
夹爪顶点、关节范围与裁剪前后力矩；积分之后读取该内步求解缓存中的
finger2–桌面及其他机器人接触。测量积分前 TCP 局部顶点相对该决策时顶点的
形变和 TCP 对投影目标的误差，并保存各自时钟；不额外调用 forward 改动物理。
力与接触标签只用于事后评价，不反馈给动作选择。形变为零的条件未在内步满足时
须明确标记，不能宣称条件包络覆盖了该内步；也不将原目标达标和投影目标达标
混为一谈。碰撞及关节安全观察不扩大为其他场景或真机保证。

## 实施和预算

每分支单独 producer 与隔离策略模块的 checker，以已派发命令独立重放，比较全部
端点、25 个关节内步、控制器目标及可重现的接触/力矩记录。除明确的比较及事后
标签外不读隐含环境真值。当前关节或刚完成内步进入原 `0.05 rad` 缓冲区时不派发
下一命令；原控制盒和每步变化上限保持不变。任何失败、拒绝或提前停止均保留，
不自动重试、覆盖已有产物或延长窗口。

每次最多 `80 + 40 + 7 = 127` 控制周期、`3,175` 个 2 ms 物理步；三分支及各自
独立 checker 总计最多六次运行、`762` 周期和 `19,050` 内步，最多 21 次新动作
选择，零新 WAM 调用、零新初态。模型/软件 context 和所需只读来源另在具体配置中
冻结并强制计数；三分支的 producer 可并发，checker 只在对应 producer 完成并
冻结后启动，所有子进程实际 wait/reap。实现前先验证精确状态恢复、因果输入、
拒绝行为、测量时序、控制限幅及 checker 隔离；zero-work dry 和 32 并发专项
通过后才执行，最后进行 64 并发相关回归。

本实验只能检验这个短窗口中同一简单控制器下参考投影的效果。若候选有收益，
仍需选择能处理持续夹爪形变和全部相关碰撞体的方法，使用各自新图像产生世界
模型参考，扩展开发初态后再执行原 18/12/24 和 600 周期稳定成功验收；如无收益
或提前停止，应按实际观测报告，不修改门槛补做。

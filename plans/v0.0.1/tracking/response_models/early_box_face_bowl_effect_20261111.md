# 提前干预中 finger1–碗接触的物体运动核查

2026-11-11。[同参考物理对照](../../../../reports/tracking/response_models/early_box_face_feedback_20261111.md)
的共同六周期中，投影分支出现 45/150 个 finger1–碗有效接触内步，而原目标分支
无此接触。碗是任务相关物体；接触本身不能判断是否符合任务意图，也不能直接推出
任务失败。本分析只读同一初态、两个已执行分支及其独立 checker 保存的状态和接触，
不重跑策略、不新选初态、不推断唯一因果。

从两组公共 step118 原生状态及 step118–123 的 12 个已保存端点，读取并固定
碗 `akita_black_bowl_1_joint0` 与奶酪 `cream_cheese_1_joint0` 的原生自由关节；
核验它们对应 world 下的原物体 body，分别计算世界位置/姿态相对公共起点的变化、
奶酪相对碗的位姿变化，以及两组同一步的差异。每个状态使用原模型做一次 CPU
`mj_forward` 核验 qpos 与 body 当前位姿一致，不推进时间，不能把结果当作新轨迹。
对共同六周期已记录的 finger1–碗有效接触，按内步统计对应 solver 缓存中的接触
法向力；不把多个接触点简单当成独立内步，不解释为真机受力或是否允许接触。
保留原任务与抓取标签，判断只能限于已记录六周期；任务成功门仍是 600 周期及
末尾连续 40 个端点，不能由当前瞬时标签替代。

来源、原模型和全部状态固定 SHA，checker 与 producer 先按原审核核对；只构建
1 个 CPU 原生模型，最多 **13 次 `mj_forward`、0 次物理积分、0 次渲染、0 次
WAM 推理、0 个新初态**。先完成 CPU 专项和零原生模型 dry，再进行一次只读
分析；失败保留，不自动重试、不覆盖既有产物。位移比较不能单独归因于某一接触，
其他场景、任务语义、连续路径与真机均未验证。

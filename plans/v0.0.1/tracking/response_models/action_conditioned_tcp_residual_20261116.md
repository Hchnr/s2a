# 动作条件 TCP 残差的因果回顾

2026-11-16。原[三任务回顾](../../../../reports/tracking/response_models/multitask_causal_tcp_innovation_20261113.md)
中上一周期偏差可降低平均预测误差，但存在假达门；新 wine 缓存候选的
[实际超限](../../../../reports/tracking/references/wine_cached_nominal_candidate_20261116.md)
也是其反例。先检查一个固定、因果的动作条件残差估计是否比上一周期偏差更能
预测已执行动作的实际 TCP 误差；不据此直接改变动作或放宽原门。

每条轨迹单独从空历史开始，使用最近最多 20 个**已完成**周期的标准化六维机械臂
命令及世界系位置预测残差。每次候选预测时，基于已完成窗口的中心化动作与残差
做带固定 `ridge=1.0` 的六输入 / 三输出岭回归，截距不惩罚；输入为当前待评动作，
位置预测加该估计残差。旋转沿用现有上一完成周期 SO(3) 创新复合，不把旋转向量
逐分量相减。每周期先评分已提交的模型预测和动作，再读取该周期实际误差更新
历史；多个同一时刻的候选查询不得改写历史。模型只使用当前动作及因果历史，
不使用任务标签、物体真值、未来状态或最终留出数据。空历史不评分；在线局部
岭求解次数单独计数，不称没有拟合。

按[固定配置](../../../../configs/tracking/response_models/action_conditioned_tcp_residual_20261116.json)
分别评分原三任务双 seed 自适应 6 条 / 1,025 周期、固定 H40 6 条 / 270 周期、
缓存 seed 候选正确参考 18 条 / 4,778 已执行周期。原 18 条中的提前停止案例
保留实际前缀与原分母，不虚构其余周期；每条首周期无历史，分别记入总数但不计
历史方法分母。另单列新 wine 候选的 144 周期及最后一次额外动作，不与其共享
前缀的原数据合并为独立样本。

对同一已执行动作比较原预测、上一周期偏差与动作条件残差：逐案例及协议报告
位置 / SO(3) 预测 RMSE、原 `0.01 m / 0.05 rad` 门下假达门和假停止，保留
所有停止及缺失。每个 producer 绑定已完成独立 checker / 审核和来源 SHA；参考
协议、初态及周期相互相关，不把 pooled 周期称为独立样本。结果已被观察，本次
是回顾性开发分析，不证明改变动作后的闭环收益、可部署安全或最终任务资格。

31 个相互隔离的 CPU worker 各处理一条已审计轨迹，单线程数值库，全部实际
wait/reap，失败不能自动重试或丢弃；总物理积分、WAM / GPU、新初态均为 0。
固定参数和方法不按结果扫描。结果若支持继续，须在另行登记的实时历史和相同
控制器上比较候选动作、独立审核与实际物理，并保留无候选和超限；仍须通过原
18 条正确参考、12 条 WAM 开发与 24 条留出要求。

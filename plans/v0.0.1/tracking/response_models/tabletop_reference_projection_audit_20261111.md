# 桌面参考投影的独立复核

2026-11-11。对已登记的 47 个状态及两种投影做独立复核：读取原始状态、
已生成目标和已固定的投影结果；不调用被审计的投影函数。分别从未移动机器人
基座的原生模型重建当前 TCP、桌面与夹爪局部顶点，再逐顶点以标量计算位置、
旋转和形变包络、桌面扩展平面、所需抬升、上限拒绝及对原始目标的偏移。
逐行核对参考本身、当前状态身份、结果、原始和投影目标误差；单独列出第 126
步仅为已生成但未执行的目标。

预算为一个模型、47 次 `mj_forward`、不移动机器人基座、零物理步、零 WAM/GPU
调用、零新初态。worker 实际 wait/reap，源身份固定；不覆盖旧记录、不自动重试。
复核只说明所设盒体、单个 finger mesh 和误差界下的静态计算一致性，不证明其他
机器人部件、路径、动力学、闭环成功或目标可达。

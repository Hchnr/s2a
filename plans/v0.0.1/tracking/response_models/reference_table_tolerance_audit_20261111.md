# 位姿容差碰撞证书的独立重建

2026-11-11。对已完成的[七目标固定夹爪证书](reference_table_tolerance_20261111.md)
进行独立只读复核。复核另起一个 native 模型，每个当前状态只做一次 `mj_forward`，
**不移动机器人基座**；直接由当前 controller site、finger geom 和已生成目标的
刚体变换重建目标 finger 位姿。重新读取编译 mesh 顶点及桌面 box，逐顶点重新
计算桌面局部坐标、六面内部余量、TCP 力臂与 `0.01 + 2 r sin(0.05/2)` 位移上界，
独立核对最大余量、见证顶点及证书标志。

绑定首轮 worker/owner、先前几何来源审计、实际状态和已生成参考 SHA；固定
step120–126 和当前夹爪配置。最多一个 native 模型、7 次 `mj_forward`、零物理
积分、零 WAM/GPU 和零新初态；显式禁止所有 `mj_step*`。先做零工作 dry 和
32 并发数值、来源及方向测试，worker 实际 wait/reap，不覆盖或自动重试。

复核证书仅对固定当前夹爪配置、固定桌面盒和原 TCP 位置/旋转容差成立；它不
排除改变夹爪开度后的可行性，不证明 IK、连续路径、真实接触力或完整任务。无
证书不是无碰撞证据。原 18/12/24 验收门槛保持。

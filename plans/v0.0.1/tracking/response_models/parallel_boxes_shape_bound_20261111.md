# 已记录 WAM 反馈的桌面、炉具和夹爪活动范围静态分析

2026-11-11。此前 correct_08、seed 42 的两条 step120–127 短窗口已各有独立
checker；位姿包络分支减少桌面接触，但出现 finger2–炉具接触，且零夹爪形变
假设多数内步不成立。此分析只使用两条已执行轨迹及其各自生成的参考，结果属于
事后开发诊断，不挑选新初态、不改变既有结果，不构成预先注册的泛化评价。
该任务要求将奶油奶酪放到碗上，炉具不是指定目标；不能据此假设其他任务或
所有期望交互都应避免与炉具接触。

在每个已记录决策端点，重建物理状态并核验 TCP、finger2 当前顶点和两个固定
盒体；参考仅取该分支当时已生成的原 WAM 目标。沿两个盒体共同向上法向，
分别计算 finger2 对桌面和炉具盒体的保守投影，再取所需抬升最大值。以相同
`0.01 m / 0.05 rad` TCP 误差界、`0.001 m` 净空、`1e-9 m` 数值余量及
`0.05 m` 平移上限比较两种夹爪形变条件：

1. 历史的零形变条件，用于保持可比；
2. 只对模型中相对 TCP 的单个平移关节，按当前关节位置与两端额定范围推导
   最大可能顶点位移。必须先核验 finger2–TCP 拓扑仅含该平移关节，TCP 不随
   该关节移动，轴与盒体变换有效；否则拒绝该条件分析。关节额定范围是条件，
   原生仿真关节约束可能为软约束，不能声称该范围在所有时刻必然满足。

记录单盒与组合所需抬升、上限拒绝、原参考修正量、已记录的实际夹爪顶点变化。
两个盒体仅在法向严格一致、沿该法向移动不改变各自水平投影时取最大值；不支持
倾斜不一致的盒体。该方法只证明给定形变、姿态与静态盒体条件下已选 finger2
顶点的保守净空；它不证明其他几何、连续路径、任务成功或真实标定，也不证明
原目标不可通过其他方向或旋转达到。不能把针对旧轨迹计算出的投影当成其会执行
后的新物理轨迹，亦不能把两条不同 WAM 参考的差异归因于单一因素。

来源、配置及结果带 SHA；输入包含此前两个 producer、各自 checker 和总体 owner，
重建的状态与已记录几何须匹配。预算最多 **1 次 CPU 原生模型构建、16 次
`mj_forward`、0 次物理积分、0 次渲染、0 次模型推理、0 个新初态**；`mj_step`
类函数显式禁止。16 个端点按固定顺序全部分析，不按结果筛选，不自动重试，不覆盖
已有产物。先完成纯 CPU 设计测试与零原生模型 dry，再执行一次静态诊断；失败及
实际预算均保留。

# step125 缓存候选的动作变化率数值修正

2026-11-11。[缓存审核](../../../../reports/tracking/joint_control/cached_live_stop125_constraint_audit_20261111.md)
中最终候选仅以约 `6.85e-12` 的名义动作变化率超差被原后置过滤拒绝。本次只取
该已登记优化器最终候选，不搜索或根据任务结果挑选。以原上一命令开始，逐周期对
每维执行原动作 box 和 `0.25 - 1e-10` 变化率交集内的确定性裁剪；额外内缩仅为
避免浮点重新落到边界之外，任何变化大于 `1e-8` 即停止。绝不放宽原约束或质量门。

在同一冻结状态、控制器、已生成参考和过去误差下，对修正计划做一次局部模型
rollout，并使用既有独立逐内环核验重新检查 box、速率、关节、0.1 s 制动、终端
及首点位置 ≤ 0.01 m、旋转 ≤ 0.05 rad（沿用原数值容差）。无论结果如何均不派发；
通过只能称为该冻结局部模型中的 witness。真实现场原失败种子未保存，修正的是
静态复核候选，不是对原真实 WAM 决策的精确复现。

最多一个模型初始化、一次不推进时间的 forward、一次修正后预览模型响应及一次
独立 witness 核验（200 端点查询、2,600 模型内转换步）；0 优化、0 物理积分、
0 新 WAM/GPU、0 新初态、不自动重试。预先测试确定性裁剪及篡改拒绝，32 并发
专项与零工作 dry 后冻结输入/源码；子进程实际 wait/reap。通过后才另行评估在线
算法与物理复现，原测试门槛和留出验收保持。

# 跨重规划的因果参考阶段记忆

2026-11-10。上一轮12条开发记录显示单次保留旧chunk的下一8点覆盖有限，同时存在
多次未来闭合/打开预测被继续推迟；单纯提前闭合和固定整块执行均已有任务负结果。
本阶段设计一个受限因果候选，先在原开发记录上做影子覆盖和输入检查，结果不计为
控制或任务成功。

## 策略与边界

策略每次仅接收当前实测TCP/开度、当时已生成的H40 TCP/开度参考、当前物理步和本
episode此前保存的一个生成参考；不接收物体、接触、任务谓词、未来观测或未来chunk。
在当前实测opening `>0.8` 时可记住已生成的首个 `<0.35` 闭合目标；在实测opening
`<0.35` 时可记住首个 `>0.8` 打开目标。仅当首事件不在当前即将执行的8点中时
保存，目标的原绝对端点及完整位姿/开度成对保留，最多保存该chunk的40点有效期。

后续每8步重规划时，用当时最新参考核对同一绝对事件端点、接下来8点及当前实测TCP：
事件与新目标位置/旋转差均不超过0.02 m/0.1 rad、完整8点均不超过该尺度，当前
TCP相对旧前缀首点不超过0.03 m/0.15 rad；当前开度仍处于事件相反区间、事件未过期、
最新参考未在原到期时刻或更早表达同类事件时，才继续保留。任一条件不满足则丢弃旧
事件，并可从当前chunk重新建立记忆。上述阈值沿用此前参考保留候选和阶段分析，
是固定实验参数，不是物理安全或正确性的证明，不按案例调参。

当事件进入下一个8步执行窗口且全部条件仍通过时，选择**原参考的同时间8点位姿与
开度整对**；否则选择最新8点。该选择明确改变最新参考消费，后续必须并列报告相对
最新及被选参考的实际误差、动作/关节约束、抓取和任务结果。它不能凭空产生没有的
事件，也不保证事件位姿可达或接触成功。新episode隔离状态；选择与状态提交分离，
只有调用方确认当前8周期实际完成才提交下一记忆；取消或异常不得混入后续历史。

## 本轮可执行验证

在原v4全部12案例、900个已生成chunk及原当前端点上做单次时间顺序影子重放，检查
每次记录仅来自此前或当前chunk、每次输出的绝对目标索引和事件有效期。逐案例报告
首次改变与全部影子触发、闭合/打开类型、记忆保留和拒绝原因；对同案例第一次改变
之后继续沿用的原观测明确标为基线影子，不能当新策略反事实轨迹。没有首事件时应
明确0触发。固定来源及前后SHA，不重新选择案例或扫描门槛。

先验证跨两次/多次重规划、正反事件、未到期、当前位姿与目标不一致、事件过期、
最新参考自行兑现、异常/重置和commit隔离；再做32并发CPU检查及零模型dry。12个
CPU worker独占目录并实际wait/reap、无自动重试。该阶段不创建仿真模型、不推进
物理、不调用WAM、不拟合、不读取final fresh或使用GPU；若覆盖不足据实保留，若
有机会再另行登记相同状态/参考的实际物理对照和独立重放，不从影子触发推断收益。
原18正确参考、12 WAM开发和24最终留出门槛均保持。

# 已保存 WAM 参考的流式执行物理准入

2026-11-11。先检验[连续执行适配器](../../../../reports/tracking/joint_control/causal_stream_execution_20261111.md)
与真实 CPU/OSMesa runtime 的衔接，再考虑新模型调用。配置固定在
`configs/tracking/joint_control/causal_stream_recorded_physical_20261111.json`；
它不修改历史 8/16 周期入口、控制器、参考、质量门或其来源。

唯一 case 为已研究的 correct_08、seed 42。仿真子进程重放原 80 周期正确参考前缀，
在实际 step80、88 捕获当前双相机图像；独立 CPU relay 子进程只返回此前已审核
的两份 WAM 响应，不初始化或调用模型。每次返回前均核对当前步、状态、仿真时间、
图像 SHA、任务、seed、历史 checkpoint 清单身份和原响应来源。每个实际完成周期
与先前独立重放过的对应命令、状态、25 个内环样本、TCP 误差、grasp 和任务谓词
对照；不一致时保留已完成动作并阻止下一次派发。历史轨迹只作复现诊断门，不是
最终在线策略输入，也不能用本实验声称模型从当前图像进行了新推理。

仿真 producer 与独立 checker 各最多 96 个控制周期、2400 个 MuJoCo 内步，合计
最多 192 / 4800；每阶段至多一次，最多两次本地保存参考读取。新模型初始化、模型
请求、去噪、训练及新初态均为 0。每份历史响应对应的 35 次去噪属于此前工作，
不得计成当前新调用。保留全部失败、局部结果、进程 wait/reap 和资源账目，不自动
重试或追加预算。任一实际 joint buffer 丢失、响应无效、状态不一致、quality witness
缺失或前缀证据不匹配均停止下一动作。

独立 checker 从同一初态重放实际已完成命令和前缀，每周期核对所有内环、端点、
目标误差及可独立计算的任务标签；候选反馈策略不进入 checker。checker 对未完成
的 in-flight 物理动作和候选策略停机原因不作认证。响应及目标来源另核验 SHA，
对任何不完整或未实际 wait/reap 的阶段不授予通过。

执行前必须完成源码冻结的 CPU 单测、64 路相关回归和零物理 dry admission；只有
输入 SHA、历史 producer/checker 与当前源码一致时才启动唯一 producer，producer
完整关闭后才启动唯一 checker。成功仅表示新流式路径在已研究初态重现已有物理
轨迹；仍是暂停物理等待、保存响应回放，并非实时 WAM 闭环或 18/12/24 最终验收。

# 四次打开事件的安全筛查与匹配反馈

2026-11-11。原12条开发记录的因果事件记忆有六条首次改变，其中两处闭合已做
匹配反馈，四处打开尚无执行证据。本计划固定此前独立复核发现的四处首次打开：
task0/s43/terminal058端点128、task1/s43/terminal058端点232、task2/s43/raw端点224
及task2/s43/terminal058端点592。它们是既有开发初态，不是四个新初态或最终留出。

## 先做静态准入

逐条读取独立shadow及checker的首次改变、原已审核step记录、保存的端点状态和该
case原XML的七个关节范围；证明case、seed、绝对事件端点、旧/新参考和实际状态
身份一致。只消费该时刻以前生成的旧chunk及当前chunk，不读取分歧后的基线观测作为
候选轨迹。按原0.05 rad缓冲对当前保存端点计分，记录全部四条及每个关节余量；小于
缓冲的案例两分支均不派发、不重放物理、保留为不可准入，不从分母删除。此筛查不
证明前一周期25个内步满足缓冲；物理执行时仍须重新检查。

## 条件准入后的物理反馈

对静态筛查合格的每条案例，从原初态和同一已完成命令前缀独立复现原端点；分别使用
相同绝对端点上的旧、最新成对TCP/开度参考，各最多执行8个50 ms周期。遵循已有
反馈合同：夹爪状态从实际已完成的历史重建，手臂和夹爪同时暂存、完成后才提交；
动作box/0.25变化率、首点0.01 m/0.05 rad质量、0.05 rad内环缓冲、额外制动和
独立witness审核均不放宽。起点或上周期实际内环低于缓冲、未获witness、实际越
关节范围均按原规则停止；不将未派发动作计为成功。grasp、物体和任务标签只供
事后评价，在线选择不得读取。

每次执行分别记录相对旧/最新参考的实际TCP和开度误差、夹爪命令及motor目标、
所有2 ms关节余量、抓取与任务端点。独立checker从原初态仅重放实际已派发命令，
不导入策略、不重新选择动作，逐项复核状态/内步/误差/标签及停止位置；未独立重求
的决策停止必须标记。两分支在共同起点之后的状态不同，不称为同状态反事实或新
WAM闭环，也不能把旧参考执行误认为最新世界模型参考跟踪。

预算先依四条全部可准入的最坏情况固定：每phase最多8个CPU/OSMesa worker、
`2*(128+232+224+592)+8*8 = 2416`个控制周期、60400个2 ms步、24个模型及24个
软件context；producer最多64次臂细化、64次质量求解、30720/10240次相应响应，
最多2416次夹爪规划和15851376条候选序列（按每次`3**8`逐项计数）。
checker不进行策略求解。各worker独占目录、实际wait/reap、无自动重试；所有来源、
参数、原始文件及资产前后校验。先完成32并发专项与零模型dry，再进行筛查；物理
phase须另用筛查结果和完整的实际预算注册。空CUDA/LD，数值库单线程，0 GPU、新
WAM、拟合和final fresh。18正确参考、12开发及24最终留出门槛不变。

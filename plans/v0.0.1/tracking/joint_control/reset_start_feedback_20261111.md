# 从复位状态开始的三任务首窗口实际反馈

2026-11-11。[现场复位准入](../../../../reports/tracking/joint_control/reset_native_admission_20261111.md)
已在 12 个已审核开发案例确认实际 step0 状态、控制器和首图与保存请求一致。现按
[总设计](reset_start_development_20261111.md)执行同一固定候选的首个 8 周期，
不使用正确参考前缀或最终留出初态。此前单线程图像不匹配的失败和其 36 模型/context
开销继续保留。

## 候选和来源

固定全部 12 个 v4 开发案例，三个任务各一个开发初态、两 seed、raw/terminal058；
只在各自现场初态及首图经原门逐字节核对后，使用该次已经生成的 H40 TCP 与 opening，
按原步时消费前 8 个目标。原请求响应是已保存模型输出，**本次不声称新 WAM 推理**；
不得读取原轨迹未来状态、命令或任务标签作为策略输入。当前现场姿态/速度、夹爪
测量、motor target、目标与已完成历史是唯一在线输入；任务成功和对象接触只在
物理周期结束后评分。三个目标对象名字由原任务合同固定，仅用于离线/端点评分。

统一手臂候选为已有 `SharedShiftFallbackAudit`：先搜索带模型余量的双点，再搜索
原门双点；仅在正常无候选、预算允许且本分支已完成计划后，才可后移并独立审核
首点。初始无已完成计划、上一命令按固定 reset 合同置零；innovation 与内环误差
初始化为零但标记历史未知。使用当前实际状态和完成后历史更新，不用真值对象或
任务标签选择。保持原 0.01 m / 0.05 rad、0.05 rad 关节缓冲、0.25 命令变化率、
20 Hz 控制和 25×2 ms 内环约束，模型安全 witness 不替代实际测量。

夹爪以原 v4 的 `LoadedVelocityControl` / `LoadedGripperTransaction` 从当前实际
opening 初始化，参数与速度包络绑定原独立审核的同一文件及 controller 配置；不使用
后来添加的 defer-close 或逐任务手工规则。实际 opening、参考 opening、夹爪命令
和 motor target 分开保存。手臂策略和状态初始化相对 v4 有变化，因此将候选整体与
同参考原轨迹比较，不把差异归因于某个组件。

## 执行、独立重放和判定

producer 12 个独占 CPU/OSMesa worker，各自在实际 reset 和首图精确门后最多执行
8 个周期。checker 从同一原初态独立复位与核对首图，不导入候选手臂/夹爪策略，只
重放 producer 实际派发的命令，核对完整状态、每个 2 ms 内环、TCP 误差、opening、
motor、任务及 grasp 标签。checker 核对停止位置和未派发，不重新求解无候选原因。
已生成参考与现场渲染使用已审计的 1→2→1 Torch canvas 线程范围；其余数值库和
OSMesa 线程环境为 1。每个 worker 独占输出，源/输入前后 SHA 核验，无自动重试。

每 phase 最多 96 控制周期/2,400 内步、36 模型/36 context；两 phase 最多
192 周期/4,800 内步、72 模型/72 context，另计已完成现场准入累计 72 模型/context。
producer 每决策最多 480 次原细化与 320 次质量响应，合计最多 46,080 与 30,720；
独立 witness 审核最多 19,200 端点查询/249,600 模型转换步。
夹爪 planner 每次最多枚举 `3^8 = 6,561` 个候选序列，producer 每 phase 最多
96 次调用/629,856 个候选序列。0 新 WAM 请求、GPU、
新初态及训练。失败或预派发停止均保留实际费用及未执行项，不补样本或放宽限制。

每个案例分别报告执行长度、实际位置/SO(3)/opening 误差、首个停止原因、全部实际
内环缓冲、动作变化、任务/grasp 标签和耗时；与同一原任务初态和参考的原 v4 首 8
周期的已保存结果作离线对照，原轨迹未保存的内环安全不冒称通过。只有完整 8 周期、
所有实际 TCP 端点 ≤0.01 m / 0.05 rad、所有实际内环关节余量 ≥0.05 rad，才称此
固定首窗口通过。该开发短窗不授予整任务、泛化、20 Hz 实时或最终留出资格；原
18 正确参考、12 WAM 开发、24 留出及总体 ≥20/24、各任务 ≥4/8 的门保持不变。

# 固定姿态下双 pad 几何的有界闭合可行性

2026-11-12。[固定 2 cm 偏移检查](../../../../reports/tracking/gripper/bowl_static_site_offset_20261112.md)
未在八个保存构型上形成双侧几何重叠，并超过原 1 cm 位姿误差门。本计划只检查同一
旧开发初态两条轨迹**第 48 周期末**的静态可能性，不运行新策略，也不修改验收。

固定目标碗及两 pad 的 box 旋转、机械臂末端姿态，允许整个夹爪平移 `t`，并允许两
侧 pad 从各自当前实际 finger joint 位置对称向内移动相同距离 `d`，`0 ≤ d ≤ min(q1,−q2)`；
两关节的原生 slide 范围分别为 `[0,0.04]`、`[-0.04,0]`，按原 XML 和保存夹爪 qpos
核对。已审核的 pad 连线指向 site 正 x；左 pad 随闭合沿该轴移动 `+d`，右 pad 为
`−d`。仅考虑对称闭合、当前姿态与静止物体，不覆盖其他关节状态、旋转、动力学或
在线可达性。为避免将刚好接触的数值边界称为重叠，要求所选的左右各一个碗 box
与各自 pad 在全部非退化分离轴上的几何重叠裕量至少 `1e-5 m`。

穷举 40×40 种左右目标 box 组合，每组以单位分离轴构造平移和 `d` 的线性不等式，
用线性规划最小化 `||t−e||∞`，其中 `e = 原模型目标 TCP 位置 − 当前实测 TCP 位置`，
均为世界坐标。该目标是原模型位姿误差的无穷范数下界：若所有组合的数值最优值严格大于
`0.010 m`（保留数值容差），仅支持在上述固定姿态、对称闭合、冻结物体及已定
`1e-5 m` 重叠裕量条件下未找到满足原位置门的构型；接触或更小裕量、可变姿态和
运动不属于该结论。若有下界不超过门的
组合，进一步寻找并独立验证欧氏误差 `||t−e||₂ ≤ 0.010 m` 的几何 witness；求解
失败记为未知，不当作不可行。候选若由离线物体真值选择，仅为开发诊断参数，未来
在线动作不得读取该真值。

固定两轨迹各 1,600 个 LP，seed42；每组保留求解状态、边界、残差和费用。先用解析
盒体与随机盒体检查线性约束，并将找到的 witness 独立代回 box 分离轴、joint 和
欧氏位置门。完成 32 并发回归及只读分析后报告所有组合，不在运行时扩展搜索或
自动重试。零新仿真模型、forward、物理步、渲染 context、世界模型请求及 fresh
案例；不能将静态 witness 当作抓取成功、实时或最终留出资格。

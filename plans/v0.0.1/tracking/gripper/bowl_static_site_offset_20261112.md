# 夹爪 site 固定偏移的离线三维几何检验

2026-11-12。[已独立复核的几何恢复](../../../../reports/tracking/gripper/bowl_pad_alignment_recovery_20261112.md)
显示两条短轨迹的最后端点右 pad 与碗在夹爪轴上分别至少相隔约 1.62 cm 和 1.80 cm；
这不能证明平移后就能接触。此探索只读取已复制的世界坐标 box 快照，不启动 MuJoCo，
不推进物理，不生成或发送 action。

以原固定 H40 和开度提前分支的端点 40、43、46、48 为固定样本。对每个样本只比较
当前快照与一个预先固定的几何假设：两个 pad box 同时沿当前控制器 site 的局部负 x
平移 0.020 m，姿态、张开度和碗的 40 个 box 均冻结。该固定方向和幅度来自已查看的
开发样本，属于事后提出的探索候选，不是留出评测；实际在线策略若采用它，只能使用
已知的机器人 site 位姿及固定参数，不能读取此处的目标物体真值。0.020 m 已超过原
0.010 m 位姿误差门；即使静态几何改善，也不能据此授予 S2A 参考跟踪资格。

对每个 pad–碗 box 对，用两盒各三个面法向及九个边叉积轴的分离轴检查。记录最大的
单位轴间隔：大于 `1e-8 m` 视为该对可证分离，小于 `-1e-8 m` 视为严格 box 重叠，
中间区域报告数值边界、不作接触判定。逐端点记录原/偏移两种构型下左右 pad 与所有
40 个 target box 的判定、最小最大间隔及 witness 轴，并记录原生接触列表作为另一
证据。严格重叠是冻结构型的几何结论，不等同 MuJoCo 力或动态稳定抓取；轴分离亦不
说明真实连续路径或机器人运动学可行。仅凭此检查不得选择原最终验收样本或修改门槛。

先以解析盒体、退化平行轴和固定 seed42 的随机旋转盒体对照独立线性约束可行性求解，
验证边界、单位、刚体坐标和不修改输入；然后运行 32 并发回归和只读分析。所有输入、
参数与结果保留指纹；零新仿真模型、forward、物理步、渲染 context、世界模型请求
和 fresh case。结果用于决定是否值得预登记物理对照，而不是直接改变在线默认策略。

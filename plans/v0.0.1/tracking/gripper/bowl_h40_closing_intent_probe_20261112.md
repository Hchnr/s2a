# 碗任务固定 H40 的加强闭合意图物理探针

2026-11-12。[固定姿态静态枚举](../../../../reports/tracking/gripper/bowl_static_close_feasibility_recovery_20261112.md)
在一个旧开发初态的两条轨迹末端发现原 TCP 位置门内的双 pad box 几何 witness，
但所找到的开度约为 0.047–0.151，远小于原模型末端 opening 0.706；这些 witness
冻结物体、忽略其他机器人几何，不能视为抓取。此计划登记一个**开发诊断**，检验
更强且更早的闭合意图在真实前向仿真中是否形成原生 grasp，不能把偏离模型开度的结果
当作原完整 state 轨迹跟踪合格。

## 同源输入与因果变换

使用旧开发案例 `task0_init0_s42_raw`、seed42、同一原 reset、首 8 周期、step8 当前
图像和当时实际收到的 H40；引用此前独立重放的原固定 H40 和[提前四周期对照](../../../../reports/tracking/gripper/bowl_h40_opening_lead_20261112.md)。
不新调用世界模型。原 H40 的 40 个 TCP 位姿目标及固定控制器不变；对已生成 opening
`o[0:40]`，在位姿索引 `i` 处采用
`clip(1 − 3 × (1 − o[min(i+8,39)]), 0, 1)`。这是从已生成参考派生的修改目标，
不是 WAM 直接输出；越过末尾时仅保持最后一个已生成目标。末端原 opening 约 0.7062，
变换后约 0.1186；增益 3 与提前 8 周期是在观察该旧开发案例后固定的探索参数，不能
作为独立留出证据。首 8 周期不应用变换。每段预览继续注明 opening 与 pose 各自的
生成和末端保持数量。

动作决策只使用当前实测机器人状态、因果历史和 step8 已完整生成的参考，不能使用
物体位置、接触或成功标签；它们仅在动作后评分。沿用原质量见证、关节缓冲、控制
命令限幅及停止规则。位姿误差仍相对原模型位姿；分别记录原始 opening 参考、变换
opening 参考、实测开度和两套误差、原生 grasp/任务成功、内步关节余量及停止原因。
两分支可能改变手臂命令和物体动力学，不能把不同后续状态称作逐时刻同状态反事实。

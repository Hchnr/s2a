# 065 夹爪释放前向响应辨识

064在位置误差很小的释放阶段仍有明显开度/电机目标滞后。先辨识现有固定Panda接口响应，不直接把历史命令用于在线策略。

仅原150训练锚点所对应30条native轨迹去重。每任务按注册首次出现顺序前8条用于fit、后2条为辨识留出，共24/6；开发、fresh、原validation不参与。固定seed42，不扫描划分或超参数。

标量模型：q_next = q + beta*(m_next-q) + gamma*(q-q_prev)，beta,gamma∈[0,1]。q为当前实测归一化开度，m_next为该控制周期已知发出的motor target对应开度；不将q_next或未来观测放入特征。native端点cache用于离线辨识已执行输入，在线只能使用当前已知cache和候选发送输入。fit仅使用motor目标不下降且高于当前q+0.02的打开加载段，不使用对象/contact/native success筛样。

同一固定模型报告fit/holdout打开段与全部有效周期的一步RMSE、保持当前q基线和逐轨迹误差。输入SHA前后复核，保存参数和确切行索引；不以离线误差宣称闭环收益。零模型/物理/fresh，CPU空CUDA/LD。

若留出不能改善，不接入逆响应；若改善，再独立设计有限参考预览的补偿并先用固定正确参考验证。原控制器接口、验收与失败记录不变。

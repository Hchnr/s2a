# 历史求解器源码身份的显式桥接

2026-11-16。旧 staged / stopped / two-step / guarded 实验链保存了历史源码
SHA；其中 `staged_first_feasibility.py` 后续改变，原有验证器直接要求历史和
当前 SHA 相等，因而拒绝载入。不得修改旧登记、替换旧文件或把现行代码称为
历史代码。

为这条已知链添加显式版本清单：逐路径固定历史 SHA、包含该字节的 Git commit
和现行实现 SHA。历史登记仍须与原输入完全相等；逐项比较 source refs 时，仅
清单中同时通过历史 Git blob SHA 与当前文件 SHA 的差异可桥接，其他差异、缺项、
顺序变化和伪造 blob 均拒绝。新增的桥接实现与清单纳入后续运行的源码指纹；
旧登记的原字段不改。只读取本仓库 Git 对象和历史输出，不执行机器人、世界模型
或历史代码。

在四个原登记边界逐一验证版本身份，并记录桥接的来源；先覆盖错 SHA、未知
差异、缺失或改变清单等拒绝路径，再运行原失败测试及其关联回归。修复只恢复
可溯源的历史证据读取，不改变实验预算、样本身份、控制资格或用户验收门槛。

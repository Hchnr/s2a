### P2 基础模块：参考轨迹、控制器与辨识

- 新增独立实例的 `PosePID` 与 `PIDConfig`；首帧不积分、不差分；重复时间戳复用命令，不重复积分；stale 反馈拒绝并冻结；大间隔与时间倒退显式重置。
- PID 微分默认作用于实测运动，减轻重规划 derivative kick；全程 base frame m/s、rad/s。接近 π 的旋转误差拒绝，采用小旋转重规划保守策略。
- 积分限幅 + 条件积分同时考虑外层速度/变化率限制及纯函数形式的最终 downstream callback；callback 可重算，但不得发送硬件。独立夹爪命令不进入 6D PID。
- 参考轨迹用 Hermite 平移与 SO(3) RotationSpline；chunk 内固定锚点，支持两条已生成参考之间 C1 混合；chunk 变更不重置 PID。末端 horizon 到期后保持 pose 并明确零前馈。
- 新增标准化 ridge 响应辨识与正则逆解，支持 diagonal/full、过去 0–3 步命令与已发生运动、lag 0–5；参数和归一化只在 fit 计算，split 支持范围包含 endpoint 检查。
- 延迟 rollout 显式队列推进，并把预测的新运动反馈到模型历史，不回放未来真实观测。
- 外部集成测试实际执行：`python -m pytest tests -q -m integration --data-config configs/droid_episode0.json`：1 passed，10 deselected。显式传 `tests` 确保 pytest 提前载入该目录 conftest 中的配置选项。
- 单元测试扩展至 PID anti-windup/释放、滤波、时间异常、状态隔离、chunk 连续性、耦合辨识/逆解及延迟因果性。首次连续性测试在有限差分采样点离接缝 1e-5 秒处的变化略超 1e-5 容差；改用 1e-6 秒检验极限连续性，未放宽容差。

### P2 选择结果与 P3 冻结设计

- 144 个响应候选：diagonal/full × history 0–3 × lag 0–5 × ridge `[1, .01, .0001]`。fit 各候选剔除跨边界支持；validation 使用共同标签 `[228,260)`（32 转移），无随机划分。全局 response/command 尺度只从 fit 获取。
- validation 选择 diagonal、history=3、lag=0、ridge=.0001，fit 有效样本 177。B rank=6、scaled condition=69.16；但最小 scaled singular value 仅 .00237，存在弱瞬时命令方向；z 轴瞬时 B 为负，不能按六轴静态正增益解释。
- validation 一步 balanced NRMSE=.13046；零运动=1.50098；上一运动=.22041。独立初始化后由模型推进的多步 velocity NRMSE=.69030，pose RMSE=.05365 m/.19258 rad；保持初态=.11483 m/.61103 rad。
- 保守 gate 已在配置/代码中固定：一步优于 zero/persistence，多步 velocity 优于 zero，位置/姿态优于 hold，B condition<10000。只允许继续做局部模型内对照，不构成真实系统可靠性判据。
- validation command NRMSE：A=1.62716，线性校准=1.76694，previous-command=.16513。校准未胜出；其输出为正则无约束逆解后显式范数投影，明确不是约束最优化解。
- `runtime.py` 提供独立可调用 `StateToActionAdapter`：当前 TCP + 已生成 chunk + 计划时间 → flange 上 PID → 7D DROID reference arm/gripper 命令。命令时域固定 fit median=.07 秒附近，反馈时域来自历史 timestamp，二者分别保存；接口不接收未来实测 dt。
- P3 冻结：analytic/linear 两种前馈分别比较 FF/P/PI/PD/PID；P `[.5,2,5]`，I `[.2,1]`，D `[.02,.1]`；仅 validation 选择。7 场景为 nominal、初偏、0.7 响应增益、额外一帧延迟、恒扰动、观测噪声、静止目标。所有数值已入 configs。
- P3 通过标准预先固定：tracking 改善≥20%，位置/姿态不退化>10%，饱和比例不增加>.05，命令变化率不增加>25%（小数值容差），静止超调不多于 .002m/.01rad。任一失败都不宣称达标。
- 预检已计算 P2 test 指标但未查看其性能，也未据此调整选择；P3 参数冻结后统一报告 test。后续重复运行只检查确定性，不用 test 调参。
- 软件闭环测试明确使用候选命令推进新状态；已验证 P 能纠正初偏，PI/PID 对恒扰动的稳态误差优于 P/PD；这只是独立合成响应的控制代码测试。当前单元测试 21 passed，1 外部测试 deselected。

## 总目标

**实现一个可复用、可验证的因果S2A：在固定机器人和控制接口下，把世界模型给出的期望state/delta_state轨迹，结合当前实测状态与历史，转成可执行action，使经过控制器和机器人后的实际状态可靠接近期望状态，并在留出的新初态上稳定完成任务。**

```text
当前图像＋任务 → 世界模型 → 期望state/delta_state → 带时间的参考轨迹
                                                        ↓
当前实测状态＋因果历史 → S2A → action → 固定控制器＋机器人 → 新实测状态
```

控制问题仍是`F_C(s_t, G_C(s_t, reference, history, dt), history, dt) ≈ s_desired`。评价实际执行后的位置、SO(3)姿态和夹爪状态误差，同时检查命令约束与任务结果。几何重建、历史action拟合、teacher loss和软件测试分别提供局部证据，不能代替执行效果。[001:36](001_state_to_action.md#L36)、[001:327](001_state_to_action.md#L327)

“固定”要求明确机器人、控制器、TCP、坐标系、单位、mask和物理时间；不声称任意机器人或接触状态存在唯一逆解。S2A在线只使用当前可用状态、因果历史和已生成参考；任务语言可进入世界模型，物体特权信息、专家未来和任务成功谓词只用于正控或离线评分。[001:53](001_state_to_action.md#L53)、[002:8](002_wam_stability_20261021.md#L8)

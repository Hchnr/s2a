# 121 期间旋转残差表示

120训练证据反对硬梯形约束，改为可学习路径残差。保持物理输出12维[位移3,世界旋转Log3,dt*下一线速度3,dt*下一角速度3]，当前世界twist为因果输入。梯形旋转Q=Exp(.5*(dt*omega_now+dt*omega_next))；编码r=Log(Exp(rotation) Q^-1)，解码Exp(r) Q。其余9通道保持。使用SO(3)乘法而非旋转向量简单相加；能精确恢复任意有限物理输出，不强制期间恒加速度。

编码允许下一反馈标签；部署解码只能使用模型预测的下一角速度，不允许真实下一反馈。固定dt=.05来自配置，验证正数有限及批次维度。先实现可复用编解码和非交换/世界坐标等变测试。尚无新候选fit或性能资格。后续训练若采用此表示需新namespace、固定训练/划分和权重、独立求解与全部原门槛；非线性解码后的旋转对action不再仿射，不可直接套原线性逆求解器。控制/WAM/fresh仍关闭。
